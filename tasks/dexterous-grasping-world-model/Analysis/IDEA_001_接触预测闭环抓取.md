## 问题与机制

### 研究问题

在相同视觉输入、动作预算和训练数据下，把触觉力的**空间分布与时间变化**作为接触世界模型的状态，是否能比“当前力值/视觉-only”更早、更可靠地预测灵巧手抓取中的滑移或释放，并据此提高闭环成功率？

### 核心假设

接触力的变化率、衰减/上升趋势和空间位置是“接触是否会继续”的中间状态。动作条件世界模型若同时预测未来接触状态、物体相对位姿和预测不确定性，控制器可以在风险上升前选择继续闭合、改变手指协同或执行小幅重规划。

### 与已有工作的关键差异

已有来源分别提供静态抓取先验（S02/S03）、视觉/触觉未来预测（S04/S05）或显式对象模型（S01），而 S07 已经覆盖动作条件触觉世界模型、人到机器人迁移、策略评估和合成轨迹。因此本 Idea 只有在证明 S07 未覆盖“抓取释放/滑移风险校准 + 风险触发重规划 + 跨对象/跨手型严格归因”时才可能保留为差异化方向。

## 最小验证

### 阶段 A：低成本离线诊断（先做）

1. 数据：使用可获得的仿真灵巧手抓取轨迹或公开触觉轨迹；每个时间窗记录视觉/点云摘要、关节状态、每指触觉力/接触位置、动作、未来 0.5 s 是否 slip/release。
2. 对照特征：
   - B0：视觉/点云 + 本体感觉；
   - B1：B0 + 当前触觉力值；
   - B2：B1 + 力的时间差分、滑动窗口趋势和空间位置；
   - B3：B2 + 候选动作（动作条件）。
3. 预测器：先用相同容量的时序分类器/轻量 latent dynamics，避免把网络规模差异误认为触觉机制收益。
4. 主要指标：未来 0.5 s release/slip AUROC、AUPRC、Brier/ECE、提前预警时间；按对象和任务留出，报告 bootstrap 区间。
5. 最小重复：至少 3 个随机种子；按对象留出而非随机帧切分，避免相邻帧泄漏。

### 阶段 B：最小闭环世界模型（A 支持后）

- 输入：历史视觉/部分点云、D(R,O) 手—物表示、关节状态、触觉空间力图与动作序列。
- 输出：未来接触状态、对象相对位姿、release/slip 风险和校准不确定性。
- 控制：短时 MPC/候选动作重排序；目标为成功率 − 风险惩罚 − 动作成本。
- 基线：静态抓取生成器 + 反应式触觉控制；视觉-only world model；无世界模型的动作策略；若可行，oracle 接触状态上界。

## 可检验预测

1. 若核心假设成立，B2 相对 B1 的未来 release/slip 预测 AUPRC 和校准会提高，且提前预警时间增加；增益在接触遮挡/部分点云场景更明显。
2. 去掉力的时间差分但保留当前力值，会显著削弱长 horizon 预测；去掉空间位置会削弱多指接触分配场景。
3. B2/B3 的预测增益只有在用于动作重规划时才应转化为闭环成功率增益；仅降低视频 LPIPS 不足以支持主张。
4. 若触觉只提供任务/对象类别捷径，按对象留出后增益会消失；这是必须报告的阴性结果。

## 设计、对照与解释规则

| 结果 | 解释 |
|---|---|
| 预测和闭环均改善，跨对象稳定 | 支持接触轨迹作为可迁移中间状态，进入正式验证 |
| 预测改善但闭环不改善 | 世界模型—控制接口或不确定性校准失败；不声称方法有效，做 MPC/动作延迟诊断 |
| 当前力值有效、时间差分无增益 | S05 现象未迁移到机器人设置；保留为边界条件 |
| 仅随机帧切分有效，对象留出失效 | 数据泄漏/对象捷径，回退并重做数据划分 |
| 所有设置无增益 | 检查传感器同步、标签定义、预测 horizon 和触觉覆盖；不直接否定世界模型方向 |

## 样本、资源与风险

- 阶段 A：每种条件建议 ≥3 个 seed、按对象留出；具体轨迹数由可获得数据决定并在实验前固定。
- 计算：轻量时序模型可在单张中端 GPU 上完成；阶段 B 的视频扩散模型暂不作为首个实验。
- 硬件：真实验证需要多指手、视觉、关节状态与同步触觉；没有触觉硬件时只做仿真/离线诊断并明确边界。
- 风险：触觉传感器延迟和零漂、仿真摩擦模型偏差、未来标签定义、动作预算不公平、世界模型滚动误差。

## 三层质量检查

- 新颖性：补查发现 S07 DexTouch-WM 已覆盖动作条件触觉世界模型、人到机器人迁移、策略评估和合成轨迹；原 Idea 不能以“首次组合”申报。下一步必须逐项阅读 S07，只有其未覆盖的风险校准、滑移/释放预警和风险触发重规划才可作为候选差异。
- 研究价值：支持时可给出接触机制和控制收益；不支持时仍能界定人类触觉现象到机器人抓取的迁移边界，并区分预测指标与控制指标。
- 可归因性：统一模型容量、训练数据、动作预算和切分；用 B0–B3、对象留出、触觉时间/空间消融和不确定性校准控制混杂。
