# Idea: 触觉失败后的恢复动作排序

## 定位

- Idea ID：`IDEA-003`
- 状态：`diagnostic`
- 目标：先做一个可在现有仿真和低维模型上完成的最小实验，不训练视频扩散模型，不做跨手型和真实硬件。
- 暂定英文题目：**Failure-Augmented Tactile Action Ranking at the Onset of Slip**

这个 idea 是对 IDEA-002 的收缩版。它不声称提出新的世界模型架构，而是检验一个具体机制：**在首次滑移或失触发生的时刻，失败轨迹是否能让一个动作条件的触觉转移模型正确排序“继续闭合、保持、重新抓取”三个候选动作？**

## 前人边界

FACT 已使用失败 rollout 监督动作条件的未来视频和任务进度，并用预测结果给候选动作打分；Dream2Fix 已从成功演示合成反事实失败和恢复轨迹。TouchWorld、FeelWorld 和 DexTacWAM 已分别覆盖预测/反应式触觉、接触与滑移状态预测及多指触觉世界动作模型。因此，本实验的贡献只能来自“灵巧手触觉接触边界上的动作排序现象和严格对照协议”，不能把失败训练或触觉世界模型本身作为新颖性主张。

## 一个明确的研究问题

在同一接触前缀和相同数据量下，加入与成功轨迹配对的**单一滑移干预轨迹**，是否能提高模型在首次滑移发生后对恢复动作的排序准确率？收益是否集中在“当前触觉观测相同但未来结果分叉”的接触边界状态？

## 最小系统

### 单一任务和状态

1. 只选一种多指抓取任务和一种手型，优先使用已有仿真环境中可记录关节、物体位姿、接触和触觉摘要的圆柱或盒状物体。
2. 观测为最近 4 帧触觉摘要、关节状态、物体相对位姿；候选动作固定为 `continue-close`、`hold`、`regrasp` 三类短动作。
3. 模型是一个低维动作条件的一步或短 horizon 转移模型，预测下一时刻接触状态、滑移概率和抓取进度。它是世界模型的最小可检验接口，不实现视频生成。
4. 只注入一种干预：接触后摩擦系数下降导致单次滑移。暂不加入延迟、遮挡、物体扰动或跨手型。

### 两个主对照

- **B0 success-only**：只用成功抓取轨迹。
- **B1 paired-failure**：加入与同一接触前缀配对的单因素滑移轨迹；成功与失败样本数量匹配。

模型容量、训练步数、动作候选、数据预算和随机种子固定。按物体实例留出，禁止相邻帧随机切分。

## 主要估计量

首要指标只有一个：**首次滑移事件后，模型把真实可恢复动作排在最高位的比例**。每个事件给出三个候选动作及其真实短 horizon 结果，报告对象分层 bootstrap 置信区间。

次要指标：

- 恢复后抓取成功率和额外动作步数；
- 滑移概率的 Brier score 和 ECE；
- 预测 horizon 内的接触状态误差；
- 在稳定接触状态上的排序变化，用来检验是否出现无关的全局收益。

## 可证伪预测

1. B1 相对 B0 的主要提升应发生在首次滑移后的动作排序，而不是稳定成功片段。
2. 如果 B1 只提高滑移分类，却不提高动作排序，说明失败数据没有提供控制价值，不能宣称世界模型改善。
3. 如果随机帧切分也得到同样收益，判定为时序泄漏并重做实验。
4. 如果 B1 在单一摩擦下降干预上有效，但对另一种未训练扰动完全失效，只报告边界条件，不扩展为通用失败恢复。

## 停止和升级规则

| 结果 | 决策 |
|---|---|
| B1 在留出物体上同时提高动作排序和恢复成功率 | 才考虑加入第二种失败类型或一台真实手；先冻结当前协议并做源码/数据审计 |
| 只提高校准，不提高排序 | 结论限定为风险估计，不继续堆叠恢复策略 |
| 没有提升或只在随机切分提升 | 停止该方向，检查标签和数据泄漏后转向其他问题 |
| 结果依赖大模型或大量失败数据 | 不称为低成本机制，退回重新设计 |

## 与已有工作的差异化边界

| 已有工作 | 已覆盖内容 | IDEA-003 只保留的差异 |
|---|---|---|
| FACT | 失败感知 WAM、未来视频/进度、候选动作评分 | 低维多指触觉、首次滑移事件、动作排序作为首要估计量 |
| Dream2Fix | 反事实失败合成、视觉恢复轨迹 | 不合成大规模视觉数据，只做配对触觉干预和控制价值测试 |
| TouchWorld / FeelWorld | 触觉预测、滑移状态和规划 | 不重新提出层级架构，只测失败数据是否改变边界状态的动作选择 |
| DexTacWAM | 多指触觉世界动作模型 | 不和其规模或任务数竞争，先做可复现实验协议和机制诊断 |

## 资源和证据要求

第一阶段只需要仿真数据和单 GPU。真正开始训练前，必须锁定一个可运行的环境、确认触觉和接触标签定义，并核验所选基线的源码或可复现实验入口。若这些条件不能满足，IDEA-003 仍停留在 idea，不进入论文主张。
