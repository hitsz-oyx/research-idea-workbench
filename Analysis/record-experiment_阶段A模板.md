# 阶段 A 实验记录模板

使用 `skills/record-experiment/SKILL.md` 的 `EXPERIMENT_RECORD` 模板。实验开始前复制本文件为带日期和编号的记录，不覆盖旧版本。

```text
experiment_id: EXP-001
source_idea_id: IDEA-001
plan_version: IDEA-001-v1
execution_status: planned
research_question: 阶段A的低成本诊断是否支持力轨迹对release/slip的增量预测？
planned_vs_actual_design_and_controls: 待填写
actual_configuration: 待填写数据、代码、seed、模型容量、切分
samples_materials_or_data_provenance: 待填写
results_with_uncertainty: 待填写所有运行与区间
all_runs_or_repetitions: 待填写，不只保留最佳运行
observations_and_deviations: 待填写观察/解释/待复验
evidence_locations: Code、Code Output、数据路径、图表
known_limits_and_missing_evidence: 待填写
next_routes: squeeze-experiment
next_skill: squeeze-experiment
```
