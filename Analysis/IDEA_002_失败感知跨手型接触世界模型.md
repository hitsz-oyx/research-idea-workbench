## 研究问题

在多指灵巧手抓取中，若机器人第一次接触出现单指失触、摩擦下降、动作延迟或物体微滑，加入失败/干预轨迹训练的世界模型，是否比只用成功演示的世界模型更能保持风险校准、预测滚动稳定性并选择有效恢复动作？这种能力能否跨手型迁移？

## 为什么这是新的问题

现有工作已经覆盖触觉世界模型、滑移预测、CEM规划、预测触觉目标、高频残差和跨手型几何世界模型。全文中仍出现一个共同缺口：DexTacWAM 明确观察到第一次执行错误后预测与动作质量恶化；FeelWorld 有滑移代价但滑移样本极少且未报告概率校准；TouchWorld 把 uncertainty-aware 触觉目标和更广泛手型迁移列为限制；S08 的跨手型世界模型没有触觉状态。因此研究对象从“再加一个触觉模块”改为“世界模型在首次接触失败后的可校准恢复能力”。

## 核心假设与机制

成功演示只覆盖稳定接触附近的状态，模型学习到的是成功轨迹流形。第一次失触或滑移把系统推向未见状态，递归预测误差和动作错误相互放大。显式加入失败/干预轨迹，并把接触模式、滑移风险和不确定性作为预测目标，能够让模型识别“当前已经不可信”，从而触发恢复动作或缩短 replanning horizon。跨手型时，用几何接触图/粒子表示作为共享状态，用手型和传感器描述作为条件，而不是直接共享原始触觉图。

## 最小验证：阶段 A（不需要真实硬件）

### 数据和干预

1. 选择两个或三个可用的仿真手型（优先与 S08 的 Allegro、LEAP、Shadow、XHand 或 Ability 配置一致）。
2. 先生成成功抓取轨迹，再只改变一个因素注入干预：摩擦下降、单指失触、动作延迟、物体初始位姿扰动、触觉遮挡/丢帧。
3. 每个轨迹记录视觉/点云、关节状态、接触图、触觉摘要、动作、未来接触模式、滑移/释放和恢复是否成功。
4. 按对象和手型留出；禁止随机相邻帧切分。

### 对照组

- B0：success-only 视觉/触觉世界模型；
- B1：B0 + 失败/干预轨迹；
- B2：B1 + 接触模式和滑移风险显式预测；
- B3：B2 + 不确定性校准与恢复动作重排序；
- B4：B3 只在训练手型上训练，测试留出手型。

模型规模、数据量、动作候选、训练步数和规划预算保持一致；先用低维接触/对象状态模型，避免一开始训练视频扩散模型。

### 主要指标

- 首次错误后的风险 Brier/ECE、AUROC/AUPRC；
- 预测 rollout 在错误发生后的接触状态误差增长率；
- 发现失触/滑移的提前时间；
- 恢复成功率、恢复动作次数和额外动作成本；
- 留出手型的性能下降；
- “预测质量→干预收益”的相关性，而不是只报告 LPIPS。

## 可检验预测

1. B1 相对 B0 的提升主要出现在首次错误之后；正常成功轨迹上的收益应较小。
2. B2/B3 应降低风险过度自信：ECE/Brier 改善，并能在失败后缩短恢复延迟。
3. 若 B4 在留出手型上失效，说明共享状态没有真正解耦 embodiment；若成功，则支持几何接触图作为跨手型中间接口。
4. 若恢复成功率提升但预测校准不提升，收益可能来自策略结构而非世界模型；必须做去掉预测风险的控制消融。

## 解释和停止规则

| 结果 | 决策 |
|---|---|
| 失败后校准和恢复均改善，并跨手型保持 | 进入阶段 B：真实/高保真触觉验证 |
| 预测校准改善但恢复不改善 | 暂停扩展模型，诊断动作重排序和执行延迟 |
| 只在随机帧切分改善 | 判定数据泄漏，回退重做切分 |
| 只在单一仿真手型改善 | 不声称跨手型，转为手型特定研究或补充适配 |
| 无改善 | 检查干预标签、传感器仿真、动作空间和失败定义，不直接否定方向 |

## 三层质量检查

- 新颖性：本轮已全文核验 S04/S05/S07–S12，并检索到 TouchWorld、FeelWorld、TacForeSight、DexTacWAM、跨手型 WM。它们分别覆盖预测、规划、反应、跨手型或触觉迁移，但尚未在当前材料中看到统一的“首次错误后退化 + 失败轨迹训练 + 概率校准 + 留出手型恢复”协议；此判断仍为 `partial`，需进一步查代码和最新版本。
- 研究价值：支持时得到失败状态建模和跨手型恢复证据；不支持时也能量化世界模型何时失去控制价值。
- 可归因性：单因素干预、成功/失败数据量匹配、对象/手型留出、风险校准与恢复消融、固定动作预算。

## 资源与风险

- 阶段 A：仿真和低维 dynamics，可在单 GPU 开始；不依赖真实触觉硬件。
- 阶段 B：需要一种多指手、触觉传感器和同步日志；重点风险是仿真摩擦与真实触觉分布差异。
- 伦理/安全：真实实验采用低速、力矩/位置限幅、急停和软物体优先；公开人类数据遵守许可证，不复制原始视频。
