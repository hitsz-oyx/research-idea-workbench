# 前人工作与差异化边界

更新时间：2026-10-06

| 工作 | 已经回答的问题 | 对本项目的直接限制 |
|---|---|---|
| [FACT](https://arxiv.org/abs/2608.10232) | 失败 rollout 可用于动作条件未来视频和任务进度训练，并支持候选动作评分 | 不能再把“失败感知世界模型”本身写成新颖性 |
| [Dream2Fix](https://arxiv.org/abs/2603.13528) | 可从成功演示合成反事实失败和恢复轨迹 | 不能再把“失败到恢复”作为宽泛贡献 |
| [Fail2Progress](https://proceedings.mlr.press/v305/huang25d.html) | 面向真实机器人失败生成针对性数据并训练恢复 | 失败数据利用已有先例，需改成明确的触觉接触问题 |
| [TouchWorld](https://arxiv.org/abs/2607.07287) | 预测式/反应式触觉模型和高频接触修正 | 不能再声称“触觉世界模型用于灵巧操作”是空白 |
| [FeelWorld](https://arxiv.org/abs/2607.24267) | 显式预测接触、力相关状态和滑移，并用于规划 | 不能再把接触/滑移预测加到模型里作为主要贡献 |
| [DexTacWAM](https://arxiv.org/abs/2609.24976) | 多指触觉世界动作模型和接触演化建模 | 不能从头搭建大规模多指视觉触觉 WAM 作为低成本起点 |

## 当前可辩护的最小空白

在上述工作之外，本项目只保留一个待验证的经验问题：**配对的单因素滑移失败数据是否在同一接触前缀下改善恢复动作排序，且收益是否集中在接触边界状态。** 这不是已证实的新颖性，只是一个可以先做的诊断假设；只有在严格留出实验中出现稳定效果，才值得继续做论文级定位。
